# Atividade 05 - Cadastro de Vinil e CD

Backend em TypeScript + Express + MongoDB e frontend em HTML/CSS/JS simples.

## Passos

1. Copie `.env.example` para `.env` e ajuste a URI do Mongo se necessário.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie em modo dev:
   ```bash
   npm run dev
   ```
4. Acesse http://localhost:3000

Endpoints principais:
- `GET /api/discos`
- `GET /api/discos/:id`
- `POST /api/discos`
- `PUT /api/discos/:id`
- `DELETE /api/discos/:id`
